## 🧩 About

**Foxhole Radar** is a comprehensive overlay tool for Foxhole featuring a live map radar, enemy tracker, loot ESP, HUD markers, and config presets.

Inspired by community mods and client-side overlays for large-scale MMO warfare.

## ✨ Features

### 🎮 Core Hacks
- Radar Overlay — real-time map scan for nearby units
- Enemy Tracker — mark hostile players and vehicles
- Loot ESP — highlight crates, salvage, and supply drops
- Distance Markers — range readout for tracked targets
- Path Lines — draw direction toward objectives

### 🎨 Interface & HUD
- Custom HUD — moveable markers and labels
- Color Presets — faction-aware highlight themes
- Minimap Zoom — adjustable radar radius
- Icon Filters — show or hide unit categories

### 🏋️ Utility & Config
- Config Profiles — save and load layouts
- Hotkey Binds — rebind every toggle
- Safe Mode — restrict noisy features
- Log Export — save session data locally
